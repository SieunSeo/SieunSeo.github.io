# Sieun Seo — Personal Research Website

Dark academic portfolio for GitHub Pages.

## Publish
1. Create a **public** GitHub repository named `SieunSeo.github.io` (GitHub treats repository names case-insensitively).
2. Upload `index.html`, `style.css`, and `.nojekyll` to the repository root (not inside a folder).
3. Go to **Settings → Pages → Build and deployment**.
4. Set **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** and save.
5. Visit `https://sieunseo.github.io/` after publication completes.

## Update
Edit `index.html` directly on GitHub and click **Commit changes**. The site redeploys automatically.

## Notes
- The publication statuses reflect the supplied information as of October 2026; keep them current.
- There is no CV download button until you explicitly add a public CV PDF.
- Check all personal details and links before publishing.
